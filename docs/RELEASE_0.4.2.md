# MurMur 0.4.2 · 本地 Beta

日期：2026-10-04。活动目录 `D:\LocalProjects\MurMur`。继续采用 Python 3.12、PySide6、uv；界面保持英文、暗色、紫色强调及固定尺寸。本轮未进行 Git 操作，没有修改发布工作目录、用户配置、历史、凭据或模型文件，没有构建便携包。

## 本轮落实的改动

### 采集与取消

`audio_capture.PCMCollector` 保留 capture-first 行为，停止请求立即封口并在后台关闭设备。新增关闭完成事件及有界等待：设备的 `stop/close` 还没完成时，识别链路不会把音频当作已经正常完成而上传；关闭失败、超时或取消分别进入保留原文的失败/取消路径。原生驱动若永久卡住，后台线程无法强制终止驱动，只能使当前操作在等待上限后失败。

`ali_nls.NlsRecorder.abort` 保留最近 pending 文本；事件在解析后再次于锁内检查取消，迟到事件不能覆盖冻结的原文。`cloud_asr.HttpAsrRecorder.abort` 保留已经完成、尚待 Qt 通知的转写，同时禁止尚未完成的请求在取消后发布结果。DashScope、离线和 HTTP 的结束链路统一等待采集清理屏障。

上一轮迁入的批处理静音裁剪、首尾余量、默认关闭的保守噪声门仍有效。**没有按键前常驻预录**；TypeFree 的 pre-roll 是已采集音频中保留起音前余量。RMS 检查不能代替语义 VAD 或神经降噪，阿里流式音频也不做事后裁剪。

### 多服务与本地安装

保留上一轮实现的 OpenAI、Groq、自定义兼容 HTTP，以及已有阿里、本地 ASR。各厂商协议、Key、模型与参数独立配置，不自动跨厂商回退。Services 的三个主卡片保持 Speech to Text / Polish / Ask Anything，细节在 Advanced。

模型安装的下载阶段、百分比和失败信息现在直接显示在 Speech to Text 主卡片上，失败后可继续进入重试流程。选择本地模型不会自动下载，Install 才启动既有校验安装器。Test 的认证/模型目录检查不等于真实音频转写验证。

### 口误与书面化

新增 `dictation_corrections.prepare_corrections`，只对有逗号停顿的明确局部更正生成独立编辑材料：相邻同类日期、相同单位数值，或值以外措辞完全相同的完整分句重说。原始转写不改。否定、不确定、边界限定、引号内、跨句、不同动作、复合/平方单位及标识符内部不作猜测。链式更正保留最终值，邻近仍有效的旧值不会被全局删掉。

`prompt_messages.PreparedDictation` 保留原文快照，发送独立编辑材料；`providers.transform` 只在普通听写开启整理时使用此流程，关闭整理直接保留转写。新增更正结果校验，错误恢复继续使用原文。真正的结构、语法和书面表达仍由 LLM 完成，规则不替代模型。

提示词版本 `dictation-compact-3`：明确固定听写模式，风险示例最多两个；语义保真优先于列表格式示例，增加禁止把独立否定改为条件许可或添加因果关系的检查。中文、英文及混语仍保留原语言，听写中的翻译/问答要求只是要整理的材料；只有明确选择 Translate 或 Ask 才执行对应操作。自定义偏好、语言/术语/引用校验和实际 usage 统计继续保留。

### 紧凑界面

词典长词条现在等高单行显示，全文可通过 tooltip 与无障碍名称读取；ASR 提示随已保存服务的实际能力变化。空历史和禁用快捷键说明指向可用的 Home / Record 控件。125% 与 150% 人工数据截图检查包含页面、设置、安装/失败、录音/处理和结果/恢复状态；不是原生桌面焦点验证。

## 公开本地模型复测

本轮先做一次六例开发中对照，再以最终源码复测 2B 同六例和已有 4B 三例，共 15 次公共文本请求。只调用已有 loopback 兼容接口，配置在内存中；不读取私人资料、密钥、录音或用户用量账目，不下载模型、不改变用户的 Auto 或配置、不调用外部付费 API。实际响应、usage、耗时和七个加载源码 SHA256 随证据交付。

独立审查最终样例的严格结果：

| 样例 | Auto 实际选择的 2B | 已有 4B |
| --- | --- | --- |
| 日期及两项任务更正 | 通过 | 通过 |
| 数值/材料更正及科学限定 | 通过 | 未重复 |
| 中文口述翻译与问答要求 | 错误翻译被拦截，整理未成功 | 通过 |
| 引用、归属、陌生名字与不确定 | 保真，但仍残留填充词 | 未重复 |
| “今天”及混语术语 | 失败：收窄为“刚刚” | 未重复 |
| 英文更正、未证明及禁止公开 | 最终日期正确，但新增 so 因果，失败 | 通过 |

2B 严格完整通过 **2/6**，另一个保真但清理不充分，一个被守卫拦截，两个语义失败。4B 此次 **3/3** 通过，范围仅限这三个样例，不是一般准确率保证。最终 2B 输入 461–656 tokens，样例约 0.469–0.907s；4B 首例未加载约 8.485s，后两例约 0.609/0.953s。加载与缓存不同，仅为描述性结果，不能当作受控性能基准。

本轮没有用“错误被拦截”冒充整理成功，也没有静默切换默认模型。小模型的语义保真仍是后续改进项；当前可以在 Polish 中明确选择已有模型，并对照历史原文检查。
