# Ask Anything 验证记录

日期：2026-10-04。本文记录本轮实现与验证边界；此前普通文字服务的真实调用不代表 Ask Anything 已完成外部服务验收。

## 已实现行为

- 默认 Right Alt + Space 开始 Ask，快捷键释放后继续录音；Right Alt 或再次触发 Ask 结束。保留左 Alt + Space 的选区编辑，以及普通听写、翻译；可改用 Ctrl + Shift + A 或禁用 Ask 快捷键。
- 使用当前选区或光标的 UI Automation 快照；密码控件、未知控件、超时、多选区、超过 12,000 字符的选区均保守回退，不自动读取未选中的整篇文档或截断选区。语音指令同样限制为 12,000 字符。
- 一次外部 OpenAI 兼容 JSON 请求返回 `replace`、`insert` 或 `answer`。改写和翻译选区请求替换；总结、解释默认回答；起草请求插入；缺少必需源文本或含糊指令请求澄清。模型没有浏览、文件操作或实时信息工具。
- 使用独立 HTTPS URL、明确模型名称及 Windows 凭据 `ask_llm`；没有本地模型或普通 LLM 密钥回退。Services 可仅移除 Ask key，不影响其他服务凭据；录音或连接检查期间禁用移除。指令与选区不应用普通听写替换规则，Ask 不套用普通文字处理的手动费率。
- 自动替换要求原选区仍可验证；自动起草插入要求原光标仍可验证。目标、输入代次、取消状态与范围在写入前复查；无法确认时保留结果供复制。回答只显示结果，Demo 不自动写入目标。
- 历史分别保存语音指令、选区上下文、结果、错误及操作类型；旧数据库追加空上下文字段，旧记录保留，搜索和 CSV/JSON 导出包含上下文。错误及取消保留已识别的指令；迟到结果不能恢复取消的会话。

## 自动测试覆盖

`test_ask_provider.py`、`test_ask_storage.py` 检查独立凭据与端点、单次 JSON 请求、严格响应解析、输入上限、HTTP/超时错误、活动请求取消、Demo、API usage、费率隔离及数据库迁移/搜索/导出。HTTP 与密钥均使用测试夹具，不调用真实外部服务。

`test_ask_hotkeys.py`、`test_ask_controller.py`、`test_text_context.py` 检查快捷键竞争与释放、延迟 Space、按键透传、AltGr/注入输入保护、录音状态、目标和范围变化、剪贴板恢复、过期结果及界面入口。UIA 和多数写入场景使用可控夹具；路由测试使用预设模型返回，不能证明真实模型必然正确判断意图。

最终完整测试结果：`uv run --no-sync pytest -q --tb=short`，**726 passed**（302.36 秒，3 条依赖弃用警告）。剪贴板修复与 Ask 控制器的后续专项复查 **65 passed**。原有工作区改动保留，未推送 Git。

## 原生 smoke 与待验收边界

脚本化原生 smoke 使用生产 UIA 快照、范围复查及剪贴板/粘贴路径；使用隔离测试窗口与合成指令/结果，不打开麦克风，不调用模型网络。它验证目标应用交互链，不构成真人讲话或物理快捷键端到端验收。

本轮原生 Windows 编辑器 smoke 的证据位于 `outputs/ask-validation-20261004/`：

| 场景 | 实际结果 | 证据 |
| --- | --- | --- |
| 选区改写 | 原编辑器收到完整替换文本，目标焦点保持 | `replace-assistant.json`、`replace-editor.json` |
| 空光标起草 | 原文末尾收到草稿，捕获状态为 caret，目标焦点保持 | `insert-assistant.json`、`insert-editor.json` |
| 选区问答 | 回答显示在气泡，原文保持，历史保存选区来源 | `answer-assistant.json`、`answer-editor.json` |
| 只读选区 | 原选区成功捕获并传给脚本模型；即使模型返回 replace，也拒绝写入 | `read_only-assistant.json`、`read_only-editor.json` |
| 模型处理中改动原文 | 新原文保持，结果仅预览，没有粘贴 | `changed-assistant.json`、`changed-editor.json` |
| 富格式剪贴板 | 首次运行自动回退到结果气泡，没有执行替换 | `rich-clipboard-fallback.json` |

`*-home.png`、`*-settings.png`、`*-result.png` 保存主页、独立 Ask 设置和结果气泡；已检查布局、入口和文字可读性。测试配置使用禁用的全局快捷键和合成密钥，因此截图中的 Disabled / key saved 不代表用户实际设置或真实鉴权结果。

测试发现并修复了合法的无所有者剪贴板状态：Win32 `GetClipboardOwner` 可返回 NULL，pywin32 却会抛出错误码 0。改为原生调用并检查真实 last-error 后，插入与事务恢复成功；新增测试覆盖空所有者、真实错误、过期 last-error、事务复原和新复制内容保护。

**测试事故记录：**为验证纯文本粘贴，辅助程序曾在 RAM 中暂存原富格式剪贴板。旧辅助程序遇到上述空所有者错误后退出，未能恢复测试前的剪贴板内容；RAM 快照已不可恢复。后续修复保证恢复错误时保留快照并重试，并验证部分写入回滚与新内容保护。此事故不涉及工作区文件，不能宣称旧剪贴板已恢复。

浏览器验证尝试被计算机操作工具停止：无法可靠确认当前 Windows 浏览器 URL，无法执行其策略检查。本轮没有取得浏览器选区与粘贴的通过证据。物理 Right Alt / AltGr 和真人麦克风录音仍待现场验证。

当前未配置独立 Ask API key，因此**尚未验证真实外部 Ask 调用**；设置中的 Test connection 使用固定短请求检查 JSON 协议，需配置并保存独立密钥后执行。仍需真人语音、不同目标应用、实际 AltGr/输入法、混合 DPI 多屏及真实模型路由质量的现场验收。此前便携包的组织安全阻挡不因源码测试通过而解除。
