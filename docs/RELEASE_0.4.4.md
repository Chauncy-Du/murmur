## 实际改动

- `editing_spans.mask_editing_spans`：在明确口误编辑材料、冻结引文之后，将唯一且可判定的混语技术/UI 名称和明确英文星期关系编码。连续且均符合条件的技术词整体保留，避免 `API endpoint` 变成两个对象；普通英语仍可改写，重复词仍可去重。先恢复编辑片段，再恢复引文。
- `PreparedDictation.restore/metadata` 与 `providers.transform`：Dictation/Refine 共用恢复与校验；原始转写独立保留，实际 API usage 在拒绝结果后仍保留，不凭字数估计、不自动再次调用。Translate/Ask 的模式和输入保持独立。
- `prompt_messages` 的 **dictation-compact-7**：最多两个风险示例，区分要求与已完成事件、明确的说话人立场和独立陈述；英文示例同时示范保留编码后的时间片段。保留专业术语、否定、不确定性、明确口误和引文，仍然改善语法、分句和组织。
- `editorial_fidelity.validate_editorial_fidelity`：限定范围内拒绝新增明确因果关系；有限句法区分角色式 `as`、日期式 `since Friday` 与有限关系从句。只检测唯一且明确的 Send/Do not publish/先或请记录 → 完成态变化。不会推断同义词、复杂动作归属或自动改回。
- `QuoteMask.restore` 和编辑标记恢复：拒绝虚构/新增重复的内部 ID，包括原 ID 被冻结在引文中的情况；保留用户原有字面 ID。修复原文空引号邻接正常引文时，完整未变返回被误拒绝的问题。
- `MainWindow.update_services_overview`：新 Test 的进行中/最终结果覆盖旧下载终态。模型“文件已验证”不再遮住后来的 Load & test 失败；Advanced 仍保留独立下载信息。
