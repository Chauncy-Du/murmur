## 改动与具体路径

- `local_llm._rank`：Auto 优先已安装且已知参数为 4–8B 的模型，范围内优先较小者；无符合模型时沿用原排序。显式指定模型、兼容接口和可选 Ollama 协议保留。模型目录与运行时仍由已有服务管理，不直接加载或下载 LLM 权重。此策略来自有限公开样例，不代表质量或性能保证。
- `service_settings` / `settings_page` / `dashboard`：Auto 策略在 Advanced 中说明，成功测试后主卡片直接显示实际模型；长名称省略但全文可读。测试弹窗区分上次完成与当前检查，Services 主卡片不增加高度。
- `providers.transform`：普通听写和明确的 Refine 共用 compact-4 提示词、JSON 编辑材料、原语言与保真校验。听写关闭整理仍不调用 LLM；用户主动 Refine 会调用。Translate/Ask 继续独立操作，不执行普通听写中提到的翻译或问答请求。
- `quotations.mask_quotations` / `QuoteMask.restore`：平衡且无歧义的原始引文替换为无冲突、固定顺序的 token；模型只整理外围正文，之后逐字恢复原标点与内容。缺失、重复、调序和新增引号包装失败；无 token 回复只接受完整原文未变的返回。嵌套、未闭合和 ASCII 单引号仍沿用原保守解析策略，不能宣称覆盖任意引号语法。
- 外围正文单独进行语言检查，原语言引文不能掩盖正文被翻译。`dictation_time.validate_dictation_time` 对两边唯一出现的完整英文星期与明确 on/by/before/after 关系检测变化；先使用局部更正后的编辑材料。未知、重复、歧义、缺少关系或其他语言不猜测，不自动改回。所有语义并未得到形式化验证。
- 结果失败气泡显示 **Copy / Review / Dismiss**；Review 进入原文编辑器，后续生成走相同守卫。失败结果不作为成功整理自动上屏，已取得的原始转写继续保留。

## 真实公开本地服务验证

仅用内存 DEFAULTS、公开固定文本和两段 SAPI 文件输出音频。没有读取私人音频、麦克风、真实用量账目或凭据；没有扬声器播放。已有 CPU SenseVoice/Silero 权重只读推理，测试前后 SHA256 相同。本轮开发中与复测共 18 次 loopback 本地文字请求；实际模型为已有 `qwen3.5:4b`，保存了实际 usage、耗时、请求/回复及加载源码哈希。
