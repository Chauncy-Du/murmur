# 气泡外观与动效

2026-10-06，本地开发版本。

在 **Settings → Appearance** 设置气泡。**Preview animation** 使用当前尚未保存的外观草稿，依次播放模拟录音、转录、整理和结果；不采集麦克风、不请求模型、不创建真实历史。点击 **Save changes** 后应用正式设置。

| 配置 | 行为 |
| --- | --- |
| Position / Display | 八种位置锚点；固定位置使用所选屏幕的可用区域。默认下方居中。 |
| Edge spacing | 与可用屏幕边缘的距离，支持 0–3650 逻辑像素，并限制在屏幕范围内。 |
| Follow mouse / Pointer spacing | 默认关闭。开启后使用鼠标所在屏幕，靠近边缘时换侧；鼠标进入气泡后暂停，方便点击。间距 12–160 逻辑像素。 |
| Capsule width / height | 宽 200–360、高 40–64，默认 224 × 44。 |
| Result width | 320–640，默认 400；正文可滚动，复制仍包含全文。 |
| Appear / Disappear | Pop、Slide、Fade 或 None。 |
| Animate state changes | 录音与处理状态淡入切换、处理阶段文字切换、胶囊到结果的展开；可独立关闭。 |
| Animate voice bars | 开启时使用现有实际音量历史；关闭后保留静态录音指示，不产生伪造音量。模拟预览明确标为 Demo。 |
| Motion duration | 120–500 ms，默认 240 ms。 |

对勾和关闭按钮采用 30 × 30 的点击区域、18 像素图标。结果气泡将状态与关闭按钮放在顶部，正文与 Copy / Edit 分区；长状态以省略号收尾，完整信息保留在提示与辅助功能文本中。

不改变已有结果交付规则：清楚并确认输入成功的听写/翻译安静结束，有疑点或未确认输入时显示结果；Copy 成功后关闭。关闭时真实控件立即隐藏，用不可点击、不会激活的短暂画面完成退场。快速重新出现会清除旧退场，避免旧动画关闭新会话。

`bubble_motion.py` 负责位置、入场、鼠标跟随与退场；`ui.py` 保留音频、进度和结果正文的原有来源。旧的 156–180 宽度低于新布局范围，升级为新的默认宽度；合法位置与其他已保存设置保留。没有修改当前模型或用户的真实历史、录音、凭据；重启现有应用加载新代码。

验证证据位于 `work/bubble-appearance-20261006`：

完整回归 **1,985 passed**；最终结果与生命周期相关回归 **97 passed**；150% 缩放界面回归 **112 passed**。完整测试有 3 条第三方依赖弃用提示。原生动画与焦点检查 11 项均通过；详见该目录的 `verification.txt`。

- 动效中间帧、最终位置、八种锚点、负坐标屏幕、鼠标换侧与悬停、开关独立性、草稿预览、快速取消等自动测试。
- 默认和 150% 缩放的设置页、三种录音模式、处理状态和结果布局渲染。
- 原生 Windows 独立测试输入框验证入场、状态过渡、结果展开与退场；各阶段输入框前台焦点保持不变，退场画面带鼠标穿透标志，结束后清理。
- 麦克风与物理快捷键没有作为本轮原生测试的输入；多显示器和鼠标跟随的边界由模拟屏幕/坐标测试覆盖。
