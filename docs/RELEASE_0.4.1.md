## 实际改动

- **录音采集**：新增 `audio_capture.PCMCollector`，用户开始后先开麦，再准备本地模型或云服务；100ms 单声道16kHz PCM帧、最多50帧准备缓存，满时终止而不丢首词。结束键在准备期间也立即封口，设备关闭在后台；取消与未发布stream/recorder竞态已有测试。界面收到实际音量帧后即可显示波形，不把麦克风已开误说成后端已就绪。默认不做idle常驻预录。
- **质量控制**：20ms RMS静音检查、批音频首250ms/尾180ms余量、保守裁剪，噪声门默认关闭。流式阿里音频已经上传，不能事后裁剪；只在停止时检查全静音。RMS不是语义VAD或AI降噪。
- **更多ASR**：新增 OpenAI（默认 `gpt-transcribe`）、Groq（`whisper-large-v3-turbo`）和自定义兼容HTTP，内存WAV批请求、独立Key与地址/模型草稿、可配置语言/超时、能力对应的热词上下文。普通识别不调用翻译接口，不跨厂商自动回退。Test只做认证/模型目录检查，真实音频调用尚未验证。
- **离线安装**：Speech to Text主卡片提供明确Install，复用现有哈希校验安装器与进度/取消；选择模型不自动下载，文件齐全也不等于模型加载成功。
- **书面化提示词**：`prompt_messages.PreparedDictation` 统一构造不可变请求；中文/混语使用中文合同、英文使用英文合同，0–2个条件示例，明确区分听写、翻译和Ask，保留语言/术语/引号运行时校验。自定义prompt继续保留，仅精确迁移已知旧默认。
- **程序稳定性**：迟到partial不覆盖final；取消/报错保留final原文；旧剪贴板恢复错误不覆盖新Bubble；模型菜单刷新保留选择，标准重复项只在端点/模型/flag精确一致时合并；会话和安装期间禁用相应服务Test。
- **版本与工程**：源码、锁文件、Qt和主页统一0.4.1，启动器传递退出码。pytest只收集当前tests；保留work旧快照。测试结束真正销毁offscreen窗口/计时器，单元测试加载前模拟音频模块，避免驱动初始化。
